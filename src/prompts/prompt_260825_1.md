# 프롬프트: 세트 설정 UI 개선 (순서 변경 + 시각화 그리드 추가)

## 목적

설정 화면(SetupScreen)에서 "세트 반복 횟수"를 사용자가 직관적으로 체감할 수 있도록 정사각형 그리드 프리뷰를 추가하고, 항목 순서와 라벨을 조정한다.

## 변경 사항

### 1. 라벨 텍스트 변경

- `src/lib/strings/ko.ts`에서 "최소 학습시간" 라벨을 **"1세트 최소 학습시간"**으로 변경
- setup 화면 관련 키를 찾아 값만 수정, 키 이름 구조는 유지

### 2. 항목 순서 변경

- 기존: 최소 학습시간 → 휴식시간 → 세트 반복 횟수 → 확률
- 변경: **1세트 최소 학습시간 → 세트 반복 횟수 → 휴식시간 → 확률**
- `SetupScreen.tsx` 내 JSX 블록의 순서만 이동. 각 항목의 상태(state)/로직은 변경하지 않음

### 3. 세트 반복 횟수 항목에 정사각형 그리드 시각화 추가

- **입력 방식은 변경하지 않음**: 기존 드래그 슬라이더 그대로 사용
- 슬라이더 바로 아래에 세트 개수만큼 작은 정사각형(또는 살짝 둥근 모서리 사각형)을 나열하는 그리드 프리뷰 추가
- 슬라이더 값이 바뀌는 즉시(드래그 중 실시간 — 기존 슬라이더의 onChange를 그대로 활용하면 자연히 실시간 반영됨) 그리드의 개수와 배열이 함께 갱신
- **배열 규칙**: 항상 정사각형에 가까운 형태로 자동 줄바꿈
  - 한 줄에 들어갈 열 개수(columns) = `Math.ceil(Math.sqrt(세트횟수))`
  - 예: 3개 → 2열(2+1행), 6개 → 3열×2행, 9개 → 3열×3행
  - CSS `grid-template-columns: repeat(columns, ...)` 또는 flex-wrap으로 구현
  - 마지막 줄이 다 채워지지 않는 경우(3, 5, 7개 등) **왼쪽 정렬**로 배치 (가운데 정렬 아님)
- **사각형 내부에는 텍스트를 넣지 않음** (예: "5분" 반복 표시 금지) — 순수한 색상 도형으로만 표시해 "덩어리감"만 시각적으로 전달
- **무제한 체크 시**: 그리드 렌더링 대신 무한대(∞) 기호나 "무제한" 텍스트로 대체 표시
- **스타일**: 기존 디자인 톤(오렌지 accent color, 둥근 모서리)과 통일. 사각형 한 변 약 20~28px 권장, 사각형 사이 gap 6~8px 권장
- **그리드 하단에 작은 요약 텍스트 한 줄 추가**: "총 예상 시간: {최소학습시간} × {세트횟수} = {합계}" 형태 (예: "총 예상 시간: 5분 × 9세트 = 45분")
  - 무제한 체크 시에는 합계 계산 불가하므로 이 요약 텍스트도 숨김 처리
  - 폰트 크기는 작게(caption 수준), 색상은 회색 계열로 은은하게 처리해 그리드보다 시각적 우선순위를 낮춤
  - 이 텍스트도 하드코딩 금지 원칙에 따라 `strings/ko.ts`에 함수 템플릿으로 추가 (예: `setup.totalTimeSummary(minTime, setCount, total)`)
- 컴포넌트 분리 권장: `SetCountGrid.tsx` 신규 컴포넌트로 만들어 `SetupScreen.tsx`에서 import (그리드 + 요약 텍스트를 함께 포함해도 되고, 요약 텍스트는 SetupScreen에서 별도 렌더링해도 무방)

## 구현 시 참고

- 새 상태 추가 없이 기존 "세트 반복 횟수" 값을 그대로 그리드 렌더링에 사용 (기존 `useSettingsStore` 등 활용)
- 텍스트 하드코딩 금지 컨벤션(CLAUDE.md/AGENTS.md) 준수 — 그리드 관련 텍스트(예: "무제한" 라벨)가 있다면 `strings/ko.ts`에 추가
- 확률 슬라이더, 휴식시간 슬라이더 등 다른 요소의 로직/스타일은 건드리지 않음

## 완료 후 확인 사항

- [ ] 라벨이 "1세트 최소 학습시간"으로 변경되었는지
- [ ] 항목 순서가 최소학습시간 → 세트반복횟수 → 휴식시간 → 확률 순인지
- [ ] 세트 반복 횟수를 드래그해서 값을 바꾸면 그리드 개수·배열이 실시간으로 함께 바뀌는지 (예: 3→6일 때 3×2 배열로 전환)
- [ ] 마지막 줄이 다 안 채워질 때(3, 5, 7개 등) 사각형이 왼쪽 정렬되는지
- [ ] 사각형 안에 텍스트("5분" 등)가 들어가지 않고 순수 도형으로만 표시되는지
- [ ] 그리드 하단에 "총 예상 시간: 5분 × 9세트 = 45분" 형태의 작은 요약 텍스트가 표시되는지
- [ ] 무제한 체크 시 그리드와 요약 텍스트 모두 정상적으로 대체/숨김 처리되는지
- [ ] 기존 다른 기능(확률 로직, 몰입 모드 등)에 영향 없는지

# 작업: pause 버튼 → 대화 프레임 변형 연출 구현

## 배경

현재 몰입 화면(VISUAL_ONLY_MODE)에서 pause 버튼(‖)을 클릭하면 임시로 설정 화면으로 바로 복귀한다. 이번 작업에서는 이 동작을 다음과 같이 교체한다: pause 기호가 스스로 변형되어 화면 중앙의 사각형 대화 프레임이 되고, 그 안에 질문과 선택지가 표시된다. 모달이 튀어나오는 게 아니라, 화면에 이미 존재하던 pause 기호가 연속적으로 변형되는 것이 핵심이다 (몰입 철학: 갑작스러운 UI 침입 금지).

## 연출 스펙 (A안: 회전 → 선 그리기)

### 타임라인 (총 약 1.2초)

1. **회전 (220ms)**: 두 세로 막대가 각각 -90°, +90° 회전하여 눕는다. 두 막대는 겹치며 시각적으로 하나의 짧은 가로선이 된다. easing: `cubic-bezier(0.4, 0, 0.6, 1)`
2. **선 그리기 (650ms)**: 누운 막대가 두 개의 SVG path로 크로스페이드(150ms)되며 교체되고, 각 path가 화면 하단 중앙에서 시작해 좌/우로 뻗어나가 → 사각형 양옆 변을 타고 올라가 → 상단 중앙에서 만나며 사각형 둘레를 그린다. stroke-dashoffset 애니메이션 사용. 그리는 동안 stroke-width는 10 → 4로 가늘어진다. `stroke-linecap: round`, `stroke-linejoin: round`. easing: `cubic-bezier(0.45, 0, 0.25, 1)`
3. **콘텐츠 페이드인 (450ms)**: 선 그리기가 거의 끝나는 시점(시작 후 약 780ms)부터 프레임 내부의 질문 텍스트와 선택지 버튼이 opacity 0 → 1로 페이드인.

### 프레임 좌표 (화면 비율 기준, 360×640 뷰포트 기준 좌표)

- 사각형: 좌 x=44, 우 x=316, 상 y=150, 하 y=560 (비율로 환산: 좌우 inset 12.2%, 상단 23.4%, 하단 12.5%)
- pause 막대 위치: 사각형 하단 변의 중앙(y=560)에 걸쳐 있음. 회전의 중심은 각 막대의 중심.
- 왼쪽 path: `M 180 560 → L 44 560 → L 44 150 → L 180 150`
- 오른쪽 path: `M 180 560 → L 316 560 → L 316 150 → L 180 150`
- path 초기 상태: 전체 길이 중 첫 30px(누운 막대 길이)만 보이게 stroke-dasharray/offset 설정 → offset을 0으로 트랜지션하면 자연스럽게 이어져 보임
- 참고: 현재 pause 버튼의 화면상 위치가 위 좌표와 다르면, 프레임 하단 변이 pause 버튼의 현재 y 위치에 오도록 좌표를 조정할 것 (연출의 연속성이 좌표 정확성보다 우선)

### 색상

- 선/막대 색: 기존 pause 버튼과 동일 계열 (`#8a7f72` 수준의 웜 그레이). 기존 pause의 opacity 0.35 은은한 상태에서 클릭 시 선명해진 상태의 색을 그대로 이어받을 것
- 배경: 기존 몰입 배경(`--immersion-bg: #201710`) 유지, 딤 처리나 오버레이 추가 금지

### 프레임 내부 콘텐츠

- 질문 텍스트 1줄 + 세로로 쌓인 버튼 2개
- 버튼 스타일: 투명 배경, 얇은 웜 화이트 테두리(rgba(242,234,217,0.3)), border-radius 10px, hover 시 배경 rgba(242,234,217,0.08)

- CLAUDE.md / AGENTS.md의 텍스트 중앙화 컨벤션 준수

## 버튼 동작 (임시)

- **"조금만 더 해볼래요"**: 프레임과 콘텐츠가 빠르게 페이드아웃(300ms)되고 pause 기호가 원래 자리·형태로 복귀(역방향 풀 애니메이션은 불필요, 단순 크로스페이드로 충분). 몰입 화면이 그대로 이어진다.
- **"여기까지 할게요"**: 기존 임시 동작과 동일하게 설정 화면으로 복귀.
- 두 핸들러 모두 별도 함수로 분리하고, 다음 TODO 주석을 유지/추가할 것:
  `// TODO: 최소 목표시간 달성/미달성에 따른 분기 반응 설계 예정`
- 내부 경과 시간 측정: 대화 프레임이 열려 있는 동안 **일시정지**하고, "조금만 더 해볼래요" 선택 시 재개한다. (이 정책은 추후 변경 가능성 있으므로 측정 일시정지/재개 로직은 독립 함수로 분리)

## 접근성

- `prefers-reduced-motion: reduce` 환경에서는 회전·선 그리기 애니메이션 생략, 프레임과 콘텐츠를 즉시 표시
- 버튼은 키보드 포커스 가능해야 하며 focus-visible 스타일 제공

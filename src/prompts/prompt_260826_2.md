# 프롬프트: 세트 설정 UI 개선 (순서 변경 + 시각화 그리드 추가)

## 목적

설정 화면(SetupScreen)에서 "세트 반복 횟수"를 사용자가 직관적으로 체감할 수 있도록 정사각형 그리드 프리뷰를 추가하고, 항목 순서와 라벨을 조정한다.

## 변경 사항

### 1. 라벨 텍스트 변경

- `src/lib/strings/ko.ts`에서 "최소 학습시간" 라벨을 **"1세트 최소 학습시간"**으로 변경
- setup 화면 관련 키를 찾아 값만 수정, 키 이름 구조는 유지

### 2. 항목 순서 변경

- 기존: 최소 학습시간 → 휴식시간 → 세트 반복 횟수 → 확률
- 변경: **1세트 최소 학습시간 → 세트 반복 횟수 → 휴식시간 → 확률**
- `SetupScreen.tsx` 내 JSX 블록의 순서만 이동. 각 항목의 상태(state)/로직은 변경하지 않음

### 3. 세트 반복 횟수: 입력 방식을 드래그 슬라이더로 전환 + 정사각형 그리드 시각화

**3-1. 입력 방식 변경**

- 기존 숫자 입력창(스피너)을 삭제하고, "1세트 최소 학습시간"과 동일한 스타일의 **드래그 슬라이더**로 교체
- 슬라이더 우측 상단에 실시간 숫자 라벨 표시 (예: "4회") — 1세트 최소 학습시간 슬라이더와 동일한 레이아웃 패턴
- **무제한 체크박스는 완전히 삭제**
- 슬라이더 범위: **최소 1회 ~ 최대 50회**
- 슬라이더 간격: **균등(linear)**. 구간별 민감도 차이 없음

**3-2. 그리드 갱신 타이밍 + 애니메이션**

- 드래그하는 동안에는 그리드를 갱신하지 않음 (숫자 라벨만 실시간 갱신)
- **마우스/터치를 뗀 순간(release)에만** 그리드가 새 개수로 갱신
- 갱신 시 사각형이 순간적으로 나타나거나 사라지지 않고, **늘어나거나 줄어드는 자연스러운 트랜지션 애니메이션** 적용 (예: scale/opacity 트랜지션, 새로 추가되는 사각형은 살짝 커지며 나타나고 제거되는 사각형은 줄어들며 사라짐. 200~300ms 권장)

**3-3. 그리드 배열 규칙**

- **열 개수는 항상 5개로 고정** (더 이상 √n 기반 가변 열 아님)
- 예: 3회 → 1줄에 3개 (왼쪽부터 배치)
- 예: 16회 → 5개씩 3줄(15개) + 4번째 줄 왼쪽에 1개
- 마지막 줄이 다 채워지지 않을 경우 **왼쪽 정렬**로 배치 (가운데 정렬 아님)
- **사각형 내부에는 텍스트를 넣지 않음** (예: "5분" 반복 표시 금지) — 순수한 색상 도형으로만 표시해 "덩어리감"만 시각적으로 전달

**3-4. 사각형 크기**

- 기존보다 훨씬 크게: 참고 이미지 기준 "작은 사각형 2×2(4개)가 뭉쳐 있는 면적" 정도를 사각형 **1개**의 크기로 설정 (기존 대비 약 4배 면적)
- 사각형 사이 gap은 크기에 비례해 적절히 조정 (예: 8~10px)

**3-5. 스크롤 처리**

- 최대 50회 선택 시 5열×10행까지 나올 수 있어 세로 길이가 매우 길어짐
- 그리드 컨테이너에 **max-height를 지정해 4~5줄 정도만 기본 노출**, 그 이상은 **세로 스크롤(overflow-y: auto)** 처리
- 스크롤 가능함을 암시하도록 그리드 영역 **하단에 은은한 그라데이션 페이드** 효과 추가 (스크롤이 끝까지 내려가면 페이드 숨김 처리)

**3-6. 요약 텍스트**

- 그리드 하단(스크롤 영역 바깥, 페이드 아래)에 작은 요약 텍스트 한 줄 추가: "총 예상 시간: {최소학습시간} × {세트횟수} = {합계}" 형태 (예: "총 예상 시간: 5분 × 9세트 = 45분")
- 폰트 크기는 작게(caption 수준), 색상은 회색 계열로 은은하게 처리해 그리드보다 시각적 우선순위를 낮춤
- 하드코딩 금지 원칙에 따라 `strings/ko.ts`에 함수 템플릿으로 추가 (예: `setup.totalTimeSummary(minTime, setCount, total)`)

**3-7. 스타일 & 컴포넌트**

- 기존 디자인 톤(오렌지 accent color, 둥근 모서리)과 통일
- 컴포넌트 분리 권장: `SetCountGrid.tsx` 신규 컴포넌트로 만들어 `SetupScreen.tsx`에서 import (그리드 + 스크롤 영역 + 요약 텍스트를 함께 포함하는 형태 권장)

## 구현 시 참고

- 기존 "세트 반복 횟수" 값(state)을 그대로 슬라이더/그리드 렌더링에 사용 (기존 `useSettingsStore` 등 활용), 타입은 숫자로 단순화
- **무제한 옵션 삭제에 따른 정리**: `useSettingsStore`, `types/index.ts` 등에 있는 무제한 관련 상태(예: `isUnlimited` boolean)와 이를 참조하는 로직(세트 진행 시 무한 반복 처리 분기 등)을 찾아서 함께 제거. 세트 진행 로직이 무제한 분기에 의존하고 있었다면 최대 50회로 대체되는 흐름으로 자연스럽게 정리
- 텍스트 하드코딩 금지 컨벤션(CLAUDE.md/AGENTS.md) 준수
- 확률 슬라이더 등 다른 요소의 로직/스타일은 건드리지 않음

## 완료 후 확인 사항

- [ ] 라벨이 "1세트 최소 학습시간"으로 변경되었는지
- [ ] 항목 순서가 최소학습시간 → 세트반복횟수 → 휴식시간 → 확률 순인지
- [ ] 세트 반복 횟수가 숫자 입력창이 아닌 드래그 슬라이더(1~50회, 균등 간격)로 바뀌었는지, 무제한 체크박스가 삭제되었는지
- [ ] 드래그 중에는 숫자 라벨만 실시간으로 바뀌고, 손을 뗀 순간에만 그리드가 갱신되는지
- [ ] 그리드 갱신 시 사각형이 늘어나거나 줄어드는 애니메이션이 자연스럽게 적용되는지
- [ ] 그리드가 항상 5열 고정으로 배치되는지 (예: 16회 → 5+5+5+1)
- [ ] 마지막 줄이 다 안 채워질 때 사각형이 왼쪽 정렬되는지
- [ ] 사각형 안에 텍스트("5분" 등)가 들어가지 않고 순수 도형으로만 표시되는지, 크기가 참고 이미지 기준 확대되었는지
- [ ] 4~5줄 이상일 때 그리드 영역에 스크롤이 생기고 하단에 페이드 효과가 보이는지
- [ ] 그리드 하단에 "총 예상 시간: 5분 × 9세트 = 45분" 형태의 작은 요약 텍스트가 표시되는지
- [ ] 기존 다른 기능(확률 로직, 몰입 모드 등)에 영향 없는지

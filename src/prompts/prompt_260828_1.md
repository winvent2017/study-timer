# 프롬프트: 몰입 도입 연출 + 어두운 세션 화면 (시각 연출 전용 모드)

## 목적

학습 세션 화면을 "카운트다운 감시 장치"에서 "몰입으로 내려가는 의식(儀式)"으로 교체한다. 시작하기를 누르면 설정 화면이 완전히 사라지고, 큰 숫자 5→1과 몰입 유도 문구가 천천히 흐른 뒤, 화면이 어두운 웜 브라운으로 가라앉으며 은은한 pause 표시만 남는다. pause를 누르면 설정 화면으로 돌아온다.

이번 작업은 **시각 연출 전용 모드**다. 기존 알람/확률/몰입 모드/축하/휴식/요약 흐름은 삭제하지 않고 플래그로 비활성화만 한다.

## 변경 사항

### 1. 색상 토큰 추가

- `src/app/globals.css`의 `:root`에 추가:
  - `--immersion-bg: #201710` (몰입 화면 최종 배경 — 순수 검정이 아닌 아주 어두운 웜 브라운)
  - `--immersion-fg: #f5ede1` (몰입 화면 텍스트/아이콘 — 순백이 아닌 웜 화이트)

### 2. 몰입 유도 시퀀스 데이터 구조 (확장성 핵심)

**2-1. 타입 정의 (`src/types/index.ts`)**

```ts
export type ImmersionStepType = "number" | "text" | "fade";

export interface ImmersionStep {
  type: ImmersionStepType;
  content?: string; // number/text 단계에서 표시할 내용
  durationMs: number; // 이 단계의 총 지속 시간
  audioSrc?: string; // 향후 음성 낭독용 (이번 작업에서는 사용하지 않음, 필드만 존재)
}

export interface ImmersionSequence {
  id: string;
  name: string;
  steps: ImmersionStep[];
}
```

**2-2. 기본 시퀀스 정의 (`src/lib/immersionSequences.ts` 신규 파일)**

- `DEFAULT_SEQUENCE: ImmersionSequence` 하나를 export
- 구성: 숫자 "5" → "4" → "3" → "2" → "1" (각 durationMs 1400) → 문구 단계 (durationMs 3500) → fade 단계 (durationMs 2000)
- 문구 내용은 `strings/ko.ts`에 정의한 키를 참조: "자, 이제 당신은 천천히 몰입의 세계에 빠지게 됩니다"
- 파일 상단 주석으로 명시: "향후 사용자 커스텀/유료 시퀀스 팩은 이 형태의 객체를 추가·교체하는 방식으로 확장한다. 재생 컴포넌트는 시퀀스 내용을 하드코딩하지 않는다."

### 3. 도입 연출 + 어두운 세션 화면 (`src/components/ImmersionSession.tsx` 신규)

**3-1. 진입 트랜지션**

- 시작하기 클릭 시 설정 화면 전체가 opacity 0으로 서서히 사라짐 (약 1.2s, ease-out). 윤곽이 남지 않고 완전히 사라진다
- 동시에 페이지 배경색이 `--background`(크림)에서 `--immersion-bg`(어두운 웜 브라운)로 천천히 전환 시작. 배경 어두워짐은 시퀀스 전체에 걸쳐 점진적으로 진행 (도입 시작~fade 단계 완료까지 서서히)

**3-2. 시퀀스 재생**

- `ImmersionSession`은 시퀀스 객체(`ImmersionSequence`)를 prop으로 받아 steps를 순서대로 재생한다 (내용 하드코딩 금지)
- number 단계: 화면 중앙에 큰 숫자 (예: text-7xl~8xl, `--immersion-fg`, 얇은 굵기). 각 숫자는 부드럽게 fade-in → 잠시 머묾 → fade-out (durationMs 안에서 자연스럽게 배분)
- text 단계: 중앙에 문구 표시 (예: text-xl~2xl, 줄바꿈 허용, 낮은 자간 여유). 마찬가지로 fade-in/out
- fade 단계: 모든 텍스트가 사라지고 배경이 최종 어둡기(`--immersion-bg`)에 도달
- 시퀀스 종료 후: 어두운 화면 + pause 표시만 남은 상태 유지

**3-3. pause 표시**

- 위치: 화면 하단 중앙 (세로 기준 대략 70~80% 지점)
- 모양: 텍스트 문자가 아닌 CSS 도형 — 굵고 둥근 세로 막대 2개 (‖). 크기 대략 막대당 너비 8~10px, 높이 36~44px, 간격 10px, `border-radius: 999px`, 색상 `--immersion-fg`
- 평소 opacity 0.35로 은은하게 존재. hover 또는 화면 아무 곳 탭/클릭 시 opacity 1로 선명해짐 (transition 0.3s). 포인터가 떠나거나 몇 초 지나면 다시 은은해짐
- 시퀀스 재생 중에도 표시할지: 재생 중에는 숨기고, fade 단계부터 서서히 나타나게 한다 (도입 연출에 시선 집중)
- 접근성: `<button>` 요소로 구현, `aria-label`은 `strings/ko.ts`에 정의한 문구 사용

**3-4. pause 동작 (이번 작업의 임시 동작)**

- 클릭 시 세션을 종료하고 최초 설정 화면(setup)으로 복귀. 세션 관련 state 초기화, 배경색 크림으로 복원
- 핸들러는 향후 분기 확장을 고려해 별도 함수로 분리: 예) `handlePauseRequest()` 내부에 "// TODO: 최소 목표시간 달성/미달성에 따른 분기 반응은 추후 설계. 현재는 무조건 setup 복귀" 주석 명시
- 내부적으로 경과 시간(elapsed)은 계속 측정한다 (화면에는 절대 표시하지 않음). 향후 달성/미달성 판정에 필요하므로 측정 로직은 유지

### 4. 기존 흐름 비활성화 (삭제 금지)

- `src/lib/config.ts` (신규 또는 적절한 위치)에 플래그 정의:
  ```ts
  // 시각 연출 전용 모드. true인 동안 알람 스케줄링/확률 판정/축하·휴식·요약 흐름을 우회한다.
  // 연출 확정 후 false로 되돌려 기존 흐름을 복원할 예정. 관련 코드를 삭제하지 말 것.
  export const VISUAL_ONLY_MODE = true;
  ```
- `page.tsx`: `VISUAL_ONLY_MODE`가 true이면 studying phase에서 기존 `StudyScreen` 대신 `ImmersionSession`을 렌더링하고, 알람 타이머 스케줄링/확률 판정/AlarmModal/Celebration/Break/Summary 전환 로직을 실행하지 않는다
- `StudyScreen.tsx`, `ImmersionMode.tsx`, `AlarmModal` 등 기존 컴포넌트와 로직은 수정·삭제하지 않는다 (잠재우기만)

### 5. 텍스트 중앙화

- 신규 문구는 전부 `src/lib/strings/ko.ts`에 추가: 몰입 유도 문구, pause 버튼 aria-label 등
- 컴포넌트 내 하드코딩 금지 (CLAUDE.md/AGENTS.md 컨벤션 준수)

### 6. 모션 접근성

- `prefers-reduced-motion: reduce` 환경: 숫자/문구를 애니메이션 없이 순차 표시하고, 배경은 트랜지션 없이 어두운 상태로 바로 전환

## 구현 시 참고

- 시퀀스 재생은 `setTimeout` 체인보다 "현재 step 인덱스 + 각 step의 durationMs" 기반 단일 타이머 진행 방식을 권장 (언마운트 시 클린업 확실하게)
- 배경색 전체 전환은 페이지 최상위 래퍼에서 처리 (CSS transition으로 `background-color` 변경). 도입~fade까지 한 번에 길게 잡아도 되고 단계별로 나눠도 됨 — 자연스러움 우선
- pause의 "탭하면 선명해졌다가 다시 흐려짐"은 마지막 인터랙션 시각 기준 타이머(예: 3초)로 처리
- audioSrc 필드는 이번에 재생 로직을 만들지 않는다. 타입에만 존재
- 세트 반복/휴식 개념은 이번 모드에서 동작하지 않는다 (pause 누르면 바로 setup 복귀). 설정 화면의 슬라이더들은 그대로 두고 값도 저장되지만 이번 세션 흐름에서는 minStudyMinutes만 경과 시간 측정의 기준값으로 내부 보관
- 이 작업으로 사용하지 않게 되는 코드가 생기더라도 삭제하지 않는다. 단, 이번 작업에서 새로 만들었다가 안 쓰게 된 코드는 남기지 말 것
